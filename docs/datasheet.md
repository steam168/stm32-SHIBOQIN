## 1. 项目概述

一台具备**硬件定时采样、乒乓缓冲、多种触发、参数测量、上位机波形导出**的便携数字存储示波器（DSO）。

全部外设驱动（SPI-TFT、ADC+DMA、输入捕获、串口 DMA）均为手写配置，无图形化配置工具依赖；
核心机制（DMA 乒乓缓冲、无帧缓冲分块刷屏、跨行区间填充画线、软件触发搜索）为独立实现。

**一句话概括技术含量**：在 20KB SRAM 的约束下，把「ADC 采集 → 内存 → 波形重建 → 显存生成 → SPI 推送」整条实时数据链路跑通，且不撕裂、不丢点。

## 2. 系统数据流

```
被测信号
   │
   ├─→ PB0 / ADC1_CH8  ←── TIM3 TRGO 硬件触发启动转换
   │        │
   │        ↓  DMA1_CH1 循环模式，256 点
   │   Buf[256] ── 半传输中断(HT) → conut=1（前128点就绪）
   │             └ 全传输中断(TC) → conut=2（后128点就绪）
   │        │
   │        ↓  主循环拷贝半屏到 Buff[256]
   │   ┌────┴──────────────────────────────────┐
   │   │ LCD_ADC_DMA : 12bit → 0~120 屏幕坐标  │
   │   │ LCD_Bo      : 5点去极值平均滤波        │
   │   │ LCD_Vpp     : 峰峰值 / 光标差值计算    │
   │   │ LCD_DMA     : 逐8行生成行缓冲 → 刷屏   │
   │   └────┬──────────────────────────────────┘
   │        ↓  行缓冲 line_buf[2][2048] 双缓冲
   │   SPI1 @36MHz + DMA1_CH3 ──→ 1.8" TFT (ST7735, 128×160)
   │
   ├─→ PB6 / TIM4_CH1 输入捕获（从机复位模式）→ 测周法求频率
   ├─→ PA1 / ADC2_CH1 旋钮电压 → 触发电平 / 双光标位置
   ├─→ PA0 / TIM2_CH1 PWM 输出 → 板载自测信号源
   │
   ├─→ USART1 @921600 + DMA1_CH4 ──→ VOFA+ 上位机（256点/帧）
   └─→ OLED (SSD1306) ──→ 常驻参数面板 Vpp / f / PSC / mode
```

## 5. 技术指标（源码推导值）

### 5.1 采样率

$$f_s = \frac{72\text{MHz}}{(ARR+1)(PSC+1)} = \frac{72\text{MHz}}{720 \times (PSC+1)}$$

| 档位 | PSC | 采样率 | 128 点对应时基 |
|---|---|---|---|
| 1 | 9 | 10 000 Sa/s | 12.8 ms |
| 2 | 71 | 1 389 Sa/s | 92.2 ms |
| 3 | 143 | 697 Sa/s | 183.7 ms |
| 4 | 719 | 139 Sa/s | 921 ms |
| 5 | 7199 | 13.9 Sa/s | 9.2 s |

> ⚠ **当前最高采样率仅 10 kSa/s，这是本项目最大短板。**
> 瓶颈不在芯片，而在配置：ARR 固定 720 过大，且 ADC 采样时间设为 55.5 周期。
> STM32F103 的 ADC 在 12MHz 时钟 / 1.5 周期采样下理论可达 ~850 kSa/s。
> 保守优化目标：**100~200 kSa/s（提升 10~20 倍）**，见 §8 改进项 P0-1。

### 5.2 其他指标

| 项目 | 参数 | 备注 |
|---|---|---|
| ADC 分辨率 | 12 bit（4096 级） | 屏幕量化到 0~120 行 |
| 输入电压范围 | 0 ~ 3.3 V | ❌ 无模拟前端，无过压保护 |
| 屏幕分辨率 | 128 × 160，RGB565 | 波形区 128 × 128 |
| 水平点数 | 128 点/屏 | 采样缓冲 256 点，半屏交替 |
| 垂直档位 | 固定（0~3.3V 全量程） | 无程控增益 |
| 频率测量 | 测周法，1MHz 计数 | `1000000/(捕获值+1)`，需外部接线到 PB6 |
| 触发 | 自动 / 上升沿单次 / 下降沿单次 | 软件搜索式，非硬件预触发 |
| 上位机 | 921600 baud，256 点/帧 | VOFA+ 兼容文本格式 |
| SRAM 占用 | ≈ 10 KB / 20 KB（约 50%） | 见下 |

**SRAM 静态占用估算**

| 数组 | 大小 |
|---|---|
| `line_buf[2][2048]` | 4 KB |
| `Clear[2048]` | 2 KB |
| `USART[2048]` | 2 KB |
| `BuF[512]` | 1 KB |
| `Buf[256]` + `Buff[256]` | 1 KB |
| **合计** | **≈ 10 KB** |

> 剩余约 10KB 需容纳栈（函数调用、`sprintf` 深度栈约 1KB+）与堆，余量偏紧。
> 这解释了为什么必须采用「无整屏帧缓冲」架构。

## 6. 关键技术实现

### 6.1 DMA 乒乓缓冲（消除波形撕裂）

DMA 循环搬运 256 点到 `Buf[]`，半传输置 `conut=1`、全传输置 `conut=2`。
主循环只处理已填满的那一半，DMA 同时在写另一半 → 采集与绘制流水并行。

```c
// Hardware/ADC.c:104
void DMA1_Channel1_IRQHandler(void){
    if(DMA_GetITStatus(DMA1_FLAG_HT1)==SET){ conut=1; DMA_ClearITPendingBit(DMA1_FLAG_HT1); }
    if(DMA_GetITStatus(DMA1_FLAG_TC1)==SET){ conut=2; DMA_ClearITPendingBit(DMA1_FLAG_TC1); }
}
```

### 6.2 无帧缓冲分块刷屏（SRAM 不足的破局）

整屏 RGB565 帧缓冲需 128×160×2 = 40 KB > 20 KB SRAM，装不下。
方案：**每次只生成 8 行的行缓冲（8×128×2 = 2KB），SPI DMA 推送，双缓冲交替，全屏 16 块**。
绘制第 N 块时，DMA 正在发送第 N-1 块 → CPU 与 DMA 并行。

### 6.3 跨行区间填充画线（消除波形断点）

逐点精确匹配 `Arrdy[x]==y` 在陡峭边沿会画成散点。改为检测**跨越关系**：

```c
// Hardware/LCD.c:342
if((curr < y && next >= y) || (curr > y && next <= y)) is_wave = 1;
```

即：某行 y 落在相邻两点之间 → 点亮。保证边沿连续。

### 6.4 5 点去极值平均滤波

`LCD_Bo()`：取前后 5 点，去掉最大最小，中间 3 点求平均。对尖峰噪声抑制有效，且计算量 O(n)，适合 72MHz 主频。

### 6.5 采样率运行时切换

直接写 `TIM3->PSC` 改档，无需重新初始化外设（预分频器有影子寄存器，下一个更新事件生效）。

## 8. 性能瓶颈分析

**为什么实际帧率上不去？**

一次完整波形刷新：

```
清屏     : 21 × 2048 B = 43 KB
波形     : 16 × 2048 B = 32 KB
SPI 传输 : 75 KB × 8 bit / 36 MHz ≈ 16.7 ms
CPU 生成 : 16块 × 8行 × 128列 = 16384 次判断（+ 清屏无生成）
          但 LCD_Clear 每次重填 2048B×21 次的循环也在 CPU 上
```

真正的 CPU 杀手是 **LCD_Clear() 每帧全屏擦除 + 逐像素判断**。
实测预期帧率约 **10~20 fps**（未用仪器验证，为推导值）。

**优化方向（收益从大到小）**

1. **脏矩形 / 只擦上一帧波形**：清屏从 43KB → 通常 < 5KB，传输量降 80%
2. **按列 Bresenham 画线**：把 16384 次"每点每行"判断降为 128 次列内垂直填充，CPU 计算量降 **1~2 个数量级**
3. 提高 SPI 时钟（ST7735 支持更高，需验证信号完整性）
4. ADC 用双缓冲 DMA 的同时，把滤波合并进采集间隙

## 9. 改进路线（按优先级）

### P0 — 让设备"能用、不烧"（1~2 周）

   - 直流偏置 1.65V → 支持交流耦合、显示负电压
   - 参考：OPA2350 / AD8065 做跟随，TL431 或电阻分压做 1.65V 基准
2. **修 ADC 时钟分频**（§7-#1）
3. **修数组越界与滤波/Vpp 计算**（§7-#2~#6）

### P1 — 让指标"拿得出手"（2~4 周）

4. **采样率提升 10~20 倍**：ARR 改小 + 采样时间改 1.5/7.5 周期 + 加 PCLK2_Div6 → 目标 100~200 kSa/s
5. **时基刻度联动**：每档对应屏幕横轴时间标注（现在是"有波形无刻度"）

### P2 — 架构升级（1~3 个月）

## 11. 附录：使用说明

1. 供电 5V / 3.3V，**输入信号务必限制在 0~3.3V，超压即烧片**
